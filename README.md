# Список задач

Сайт позволяет добавлять задачи, отмечать их выполненными и удалять. Задачи сохраняются после обновления страницы: данные хранятся в localStorage браузера.

Основной запуск требует Docker и Docker Compose. В папке проекта выполните:

```sh
docker compose up --build
```

Откройте http://127.0.0.1:8000 в браузере. Ctrl+C останавливает запуск в терминале. Чтобы удалить контейнер и сеть, выполните:

```sh
docker compose down
```

Альтернативный запуск требует Python 3. В папке проекта выполните:

```sh
python3 server.py
```

Откройте http://127.0.0.1:8000 в браузере. Чтобы остановить сервер, нажмите Ctrl+C в терминале.

Оба способа используют порт 8000, поэтому не запускайте их одновременно. Задачи сохраняются в localStorage браузера; контейнер их не хранит.
